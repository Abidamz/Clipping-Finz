# Branding — CLIP DROPS

For the `clipdropsonly` page (gaming-wide).

| File | Use | Instagram spec |
| --- | --- | --- |
| `pfp.png` | Profile picture | 320x320 min, displayed as a circle |
| `banner.png` | Header banner | 1080x566 recommended (crops to 320px tall on mobile) |

## PFP
White play-triangle merged with a film-strip notch. Cyan rim on the left edge,
warm orange on the right. Reads clearly at small sizes because the shape is
a single high-contrast silhouette.

Crop it centered when uploading — the mark sits mid-frame so a circular crop
keeps it whole.

## Banner
Wordmark `CLIP DROPS` is centered horizontally and vertically with an orange
underline, on near-empty dark space with only faint teal (left) and orange
(right) edge glows.

**Mobile safe zone:** phones show only the center strip of the banner, so all
content lives in the middle third. Nothing important sits in the outer 25% of
either side — that area exists only to fill wide desktop layouts.

## Upload order
1. Instagram app -> Profile -> Edit profile -> change photo -> pick `pfp.png`
2. Profile -> Edit profile -> drag the banner or tap "Edit cover"/"Edit profile"
3. Bio (suggested):
   `Short clips. New drops weekly.`
   `Games, updates, hype moments.`
   `Collabs & paid promos: DM`

Do not put campaign or `#Ad` language in the bio — disclosure belongs in each
post's caption.
